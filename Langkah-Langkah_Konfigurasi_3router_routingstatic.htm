LANGKAH-LANGKAH KONFIGURASI ROUTER 3

1. Membuat Bridge dan Memasukkan Port (Bridge Interface)

  • Tujuan: Menggabungkan interface ether2 dan ether3 ke dalam satu grup logical (bridge1) agar berada di segmen jaringan yang sama.

1. Membuat Bridge dan Memasukkan Interface

  • Masuk ke menu Bridge > klik tombol + (New).
  • Isikan nama bridge1 > klik OK.
  • Pindah ke tab Ports > klik tombol + (New).
  • Pilih Interface ether2, Bridge>pilih bridge1(yang tadi dibuat) > klik OK.
  • Klik tombol + (New) lagi > pilih Interface ether3, Bridge>pilih bridge1 > klik OK.

 

Memasukan interface

2. Mengaktifkan DHCP Client

Tujuan: Meminta alamat IP secara otomatis pada ether1 karena terhunung ke router 2()

  • Masuk ke menu IP > DHCP Client > klik tombol + (New).
  • Pilih Interface ether1 > centang Use Peer DNS dan Add Default Route > klik OK.
  • Pastikan status bertuliskan bound dan mendapatkan IP.

Tujuannya (use peer dns): Agar router dan client bisa langsung menerjemahkan nama domain web (seperti google.com) menjadi alamat IP tanpa perlu mengisi IP DNS secara manual.

Tujuannya (add default route) : Agar router tahu ke mana harus mengirimkan data jika client ingin mengakses atau internet.

Tujuan centang (Use Peer NTP) : fitur untuk mencocokkan jam dan tanggal router secara otomatis mengikuti waktu dari router utama atau server internet.


 

3. Menambahkan IP Address Manual

Tujuan: Memberikan gateway/IP Address pada interface yang menuju ke PC lokal sesuai ketentuan topologi.

  • Masuk ke menu IP > Addresses > klik tombol + (New).
  • Masukkan Address 192.168.4.1/26 pada Interface ether4 > klik OK.
  • Klik tombol + (New) > masukkan Address 192.168.4.65/27 pada Interface bridge1 > klik OK.

 

4. Mengaktifkan DNS (Domain Name System)

  • Tujuan: Agar router dapat menerjemahkan nama domain/IP dan membagikan layanan DNS ke PC client.
  • Langkah Konfigurasi:

1.     Buka menu IP > DNS.

2.     Centang centang pada Allow Remote Requests.

 

 

6. Mengatur Firewall NAT

Tujuan : mentranslate ip privat menjadi ip publik

  • Masuk ke menu IP > Firewall > tab NAT > klik tombol + (New).
  • Pada tab General, isi Chain srcnat dan Out. Interface ether1.
  • Pindah ke tab Action, pilih Action masquerade > klik OK.

 

 

 

 

 

5. Membuat DHCP Server untuk Client

  • Tujuan: Membagikan IP Address secara otomatis kepada PC lokal

·         ·  Masuk ke menu IP > DHCP Server > klik tombol DHCP Setup.

·         ·  Pilih Interface bridge1 > klik Next sampai selesai.

·         ·  Klik tombol DHCP Setup lagi > pilih Interface ether4 > klik Next sampai selesai

 

 

 

7. Menambahkan Routing Static (IP Routes)

  • Tujuan: Memastikan Router 3 mengenali segmen IP dari Router 1 dan Router 2,agar bisa saling mengirim pesan.

·          Masuk ke menu IP > Routes > klik tombol + (New).

·          Isikan Dst. Address ke jaringan Router 1 dan Router 2.

·           Rute ke jaringan Router 1 ( dan )

·         Rute ke jaringan Router 2 ( dan )

·          Masukan gateway mengarah ke IP Router tetangga yaitu(20.20.20.1)> klik OK.

 

 

 

8. Pengujian dan Verifikasi Jaringan (Testing)

  • Tujuan: Memastikan client mendapatkan IP dan jalur komunikasi sudah terhubung (Reply).
  • Langkah Pengujian:

1.     Cek IP Client: Buka Command Prompt (cmd) di PC lokal, ketik ipconfig untuk memastikan PC memperoleh IP default gateway sesuai segmennya ( atau ).

2.     Ping Router 2: Lakukan ping 192.168.2.62 dan ping 192.168.3.254.

3.     Ping Router 1: Lakukan ping 192.168.1.77 dan ping 192.168.1.61.

4.     Jika semua tes menghasilkan response Reply, maka konfigurasi Router 3 berhasil 100%
